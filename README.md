# Electronic engineering portfolio

A responsive, static portfolio built with Bootstrap for GitHub Pages. No build step is required.

## Customize

- Edit `index.html` to update the introduction, interests, and GitHub link.
- The three projects are **concepts**, not claims of completed work. Replace them with your own projects, descriptions, and links.
- Adjust colors and styling in `style.css`.

Bootstrap and the optional Google Fonts are loaded from CDNs; the page uses system fonts if the fonts are unavailable.

## Preview and publish

Open `index.html` in a browser, or serve the repository locally with `python3 -m http.server` and visit `http://localhost:8000`.

For GitHub Pages, configure the repository to deploy from the desired branch and its root directory. The root `index.html` is the published entry point.
